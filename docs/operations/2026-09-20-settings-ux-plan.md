# 설정 UI/UX와 리더 옵션 고도화 계획

작성일: 2026-09-20. 상태: 구현 진행 중(S0 완료).
검토 기준: PR #51의 `cd7bc8f` 및 사용자가 제공한 Moon+ Reader·Mangayomi 화면 6장.
계획 브랜치: `docs/settings-ux-plan`. 이번 작업은 코드 조사와 계획 문서 작성만 한다.

## 1. 목표와 우선순위

1. 설정 화면을 스크롤하다 값이 바뀌는 실수를 막고, 원하는 수치로 쉽게 조절한다.
2. 독서를 중단하지 않고 자주 쓰는 보기 옵션을 바꾼다.
3. 앱 모양, 리더 보기, 작품 소스, 기능 확장, 다운로드, 동기화를 찾기 쉬운 위치로 나눈다.
4. 기존 옵션을 먼저 정리하고 실용적인 고급 옵션을 추가한다. 옵션 수 자체를 목표로 삼지 않는다.
5. 긴 텍스트와 이미지가 많은 만화에서 위치 유지·입력 반응·저장 안정성을 지킨다.

Moon+ Reader는 첨부 화면의 조판 옵션 구성과 정밀 조절 방식을 참고한다. Mangayomi는 설정 분류,
저장소 관리, 설치/업데이트 상태의 표현을 참고한다. Android 전용 기능을 웹 설정에 그대로 복제하지 않는다.

## 3. 설정 메뉴와 명칭 제안

추천 명칭은 **콘텐츠 소스**와 **기능 확장**이다. 전자는 ‘작품을 어디서 가져오는가’, 후자는 ‘앱에 어떤
기능을 더하는가’를 설명한다. ‘익스텐션’은 사용자 메뉴 이름에서 줄이고 파일 형식/실행기 이름은 상세 정보에 둔다.

```text
설정
├─ 화면과 테마         앱 색상·테마·화면 표시
├─ 리더                텍스트 / 만화·이미지 / PDF
├─ 조작                탭 영역·스와이프·키보드·화면 유지
├─ 콘텐츠 소스         사용 중 / 확장 찾기 / 저장소 / 업데이트
├─ 다운로드와 저장공간 정책·작업 현황·저장 위치·사용량
├─ 동기화와 백업       서버·클라우드·동기화 상태·백업/복원
├─ 기능 확장           듣기·정보 보강 등 현재 지원하는 기능
└─ 앱 정보             버전·진단·라이선스
```

| 기존 위치                     | 새 위치                           | 이전 동선 유지                                            |
| ----------------------------- | --------------------------------- | --------------------------------------------------------- |
| 화면의 앱 UI 테마             | 화면과 테마                       | 현재 앱 테마 값 그대로 사용                               |
| 화면의 리더 글꼴/색상 + 본문  | 리더 → 텍스트                     | 이전 `appearance/layout` 진입 요청을 새 하위 위치로 매핑  |
| 조작                          | 조작                              | 기존 제스처 값과 키보드 입력 유지                         |
| 소스의 Dropbox/외부 서버 연결 | 콘텐츠 소스 → 사용 중 → 연결 관리 | 파일을 읽는 연결임을 표시. 동기화 연결과 혼동하지 않게 함 |
| 익스텐션의 소스 패키지        | 콘텐츠 소스                       | 설치·검토·복원 로직 재사용                                |
| 익스텐션의 듣기/정보 보강     | 기능 확장                         | 기존 세부 설정 패널 재사용. 공급자 설정으로 연결          |
| 별도 동기화 패널              | 동기화와 백업                     | 기존 전용 진입점도 동일 화면으로 연결                     |

PDF는 텍스트 조판 옵션을 억지로 노출하지 않고 기존 확대·맞춤·회전 등 지원 기능만 표시한다.
단일 패키지가 여러 기능을 제공해도 설치 레코드와 업데이트 작업은 하나다. 관련 위치에서 같은 패키지 상세를 열며,
삭제하면 함께 없어지는 소스/기능을 보여 준다.

### 화면 구성

- 데스크톱: 왼쪽 분류, 오른쪽 본문. 모바일: 설정 분류 목록 → 상세 화면 → 뒤로. 8개 탭을 가로로 압축하지 않는다.
- 상세 페이지는 짧은 섹션과 설명, 정렬된 컨트롤로 구성한다. 자주 쓰지 않는 옵션만 ‘고급’으로 접는다.
- 제목 옆에 적용 범위와 저장 상태 표시. 오류 시 값을 유지하고 재시도 제공.
- 설정 검색은 메뉴 구조가 안정된 다음 작은 정적 항목 목록으로 추가한다. 별도 검색 서버는 만들지 않는다.
- 삭제/초기화는 일반 토글과 분리해 페이지 아래 관리 영역에 둔다.
- 360/390px 화면과 큰 글자에서도 한 글자씩 세로로 감기거나 페이지 전체가 가로 스크롤하지 않게 한다.

## 4. 슬라이더 오조작 방지: 최우선

대상은 **설정값을 바꾸는 슬라이더**다. 회차/페이지 탐색 바의 트랙 탭 이동은 목적이 다르므로 그대로 둔다.

동작 계약:

1. 트랙의 빈 곳을 누르거나 트랙 위에서 화면을 세로로 스크롤해도 값은 변하지 않는다.
2. 손잡이의 충분한 터치 영역(약 44px)에서 시작한 수평 드래그만 값을 바꾼다. 손잡이 자체는 더 작게 표시해도 된다.
3. 손잡이 근처를 누르는 순간 값이 뛰지 않도록 현재 값과 시작 좌표의 차이로 이동량을 계산한다.
4. 수직 의도가 먼저 드러나면 페이지 스크롤로 넘긴다. 트랙에는 세로 pan을 허용하며 가로 드래그와 충돌하지 않게 한다.
5. `pointercancel`, 포커스 이동, 패널 닫기 때 드래그 상태를 해제한다. 취소된 드래그는 시작값으로 되돌리고 저장하지 않는다.
6. 양쪽 ± 버튼은 한 step씩 조절. 현재 숫자를 누르면 직접 입력 가능. 단위·범위·step은 한 정의에서 사용한다.
7. 키보드 방향키/Home/End 및 스크린리더 값 증감은 유지한다. 모든 값 변경을 pointer 입력으로만 제한하지 않는다.
8. 범위 끝, 소수점 step, RTL에서도 값이 튀거나 float 잔여 숫자가 보이지 않게 한다.

기존 range의 접근성을 최대한 유지하되, 브라우저별 native thumb 이벤트 구분에 기대어 대충 차단하지 않는다.
한 공용 컨트롤에서 위 계약을 구현하고 텍스트/만화/듣기의 설정 슬라이더를 순차 적용한다. 새 UI 라이브러리는 우선 도입하지 않는다.

성능 규칙:

- 조절 중 숫자와 작은 샘플 미리보기만 업데이트한다. 글꼴·여백·줄간격처럼 조판을 바꾸는 값은 드래그 종료 시 본문에 반영한다.
- ± 반복과 키보드는 짧은 입력 묶음으로 합쳐 반영한다. 색상처럼 조판과 무관한 값은 가볍게 즉시 반영할 수 있다.
- 기존 직렬 자동 저장 경로를 사용한다. 빠른 보기와 전체 설정이 별도의 저장 작업을 서로 덮어쓰지 않도록 한다.
- 설정 적용 시 텍스트 원문 anchor/만화 페이지 내 상대 위치를 유지한다. 글자 크기를 움직일 때 전체 회차를 매 프레임 재조판하지 않는다.

## 5. 리더 빠른 보기 옵션

기존 리더 도구 모음의 설정 진입에 **보기 옵션**을 제공한다. 모바일은 아래 시트, 데스크톱은 작은 팝오버로 연다.
전체 설정 화면과 동일한 값·검증·저장 경로를 사용한다.

| 리더   | 바로 보이는 항목                                                         | 상세로 이동                      |
| ------ | ------------------------------------------------------------------------ | -------------------------------- |
| 텍스트 | 글자 크기 ±/숫자, 테마, 줄 간격, 여백 프리셋, 스크롤/페이지, 한 쪽/두 쪽 | 글꼴·조판·테마 전체 설정         |
| 만화   | 한 쪽/두 쪽/세로·경계선 없음, 맞춤 방식, 읽기 방향, 배경, 간격           | 색 보정·자르기 등 기존 만화 설정 |
| PDF    | 확대·페이지/폭 맞춤·회전·연속 보기 등 현재 지원 항목                     | PDF 상세 설정                    |

패널 상단에 `이 기기의 기본값` 또는 `이 작품에만 적용`을 표시한다. 최초 도입 시 기존 적용 의미를 유지하고,
작품 override가 있는 경우 그 상태를 분명히 표시한다. ‘기본값으로 사용’은 명시적 동작이다.
두 쪽 보기가 선택됐어도 좁은 화면에서는 ‘현재 화면은 한 쪽으로 표시’라고 설명한다.

본문 일부를 볼 수 있는 높이로 시작하고 상세 조절은 확장한다. 패널 조작은 본문 페이지 넘김으로 전파하지 않는다.
뒤로/Escape/닫기와 포커스 복귀를 처리하며, 드래그 중 바깥을 누른 것으로 오인해 닫지 않는다.

기존 옵션은 없던 기능으로 다시 만들지 않는다. 아래는 구현 단계를 결정할 기능 목록이다.

| ------------------------------- | ----------------------- | -------------------------------------------------------------------------------------- |
| 글꼴·사용자 폰트·굵기           | 있음                    | 한곳에 정리, 폰트 미리보기와 누락 폰트 fallback 표시                                   |
| 크기·자간·줄/문단 간격·들여쓰기 | 있음                    | 손잡이/±/숫자 조절, UI와 저장 범위 통일. 큰 글자 11~40px 범위 우선 유지                |
| 왼쪽/양쪽 정렬                  | 있음                    | 기존 제공. 가운데/오른쪽은 고급 옵션으로 추가 검토                                     |
| 좌우/상하 여백                  | 축별 묶음(vw/vh)만 있음 | ‘함께 조절’ 기본, 필요 시 네 방향 분리. 기존 단위를 자동으로 px로 바꾸지 않음          |
| 단어 간격                       | 없음                    | 고급 옵션. 단위 명시, 실제 렌더링·페이지 측정에 동시에 적용                            |
| 줄바꿈 규칙                     | 전용 설정 없음          | 기본 / 단어 우선 / 글자 단위. 한국어·라틴문자·긴 URL을 함께 확인                       |
| 기울임·밑줄                     | 전역 옵션 없음          | 선택형 스타일로 추가, 기본 꺼짐. 밑줄과 링크의 구별 유지                               |
| 글자 그림자                     | 전역 옵션 없음          | 후순위. 낮은 강도 1~2개로 제한, 큰 blur나 중첩 그림자 제외                             |
| 글자/배경 색·기본 테마          | 있음                    | 독립 리더 테마 섹션으로 정리, 사용자 테마 저장/이름 변경/불러오기 추가                 |
| 배경 이미지·농도                | 없음                    | 후순위 선택 기능. 크기 제한·단일 배경 레이어, 폰트/이미지 원본을 설정 JSON에 넣지 않음 |
| 한/두 쪽·전환 효과              | 있음                    | 빠른 보기에서 접근, OS 동작 줄이기 준수. 종이를 휘는 물리 page-curl은 이번 범위 밖     |
| 본문 세로 정렬                  | 없음                    | 마지막 우선순위. 페이지 모드에만 검토하고 스크롤에는 노출하지 않음                     |
| 안티앨리어싱·글자 장평          | 확실한 공용 제어 없음   | 첫 구현에서 제외. 브라우저별 차이 및 transform 기반 장평의 페이지 측정 불일치 위험     |
| 텍스트 인코딩                   | 보기 옵션의 역할이 아님 | 필요하면 가져오기/다시 해석하기에서 원본 보존·변경 미리보기로 별도 검토                |

Moon+ Reader의 모든 토글을 그대로 만들지 않는다. 위 옵션 중 1차는 기존 옵션 정리·네 방향 여백·줄바꿈·
단어 간격·사용자 테마까지다. 페이지 측정과 실제 표시의 일치가 어려운 옵션은 별도 단계로 남긴다.
초기화는 ‘이 항목’, ‘이 섹션’, ‘이 작품의 재정의 해제’를 구분한다. 스타일 초기화가 제스처나 계정 연결을 지우지 않는다.

## 7. 콘텐츠 소스와 저장소 관리

### 사용 중 / 확장 찾기 / 저장소 / 업데이트

- **사용 중:** 소스 검색, 소설/만화·언어·상태 필터, 즐겨찾기, 연결/세부 설정/작품 탐색으로 이동.
- **확장 찾기:** 설치 가능한 패키지. 설치됨·업데이트 가능 상태를 정확히 표시하고 중복 설치 버튼을 막는다.
- **저장소:** 이름·URL·형식·지원 콘텐츠·마지막 확인·오류를 카드에 표시. 추가/새로고침/URL 복사/열기/제거.
- **업데이트:** 설치 버전 → 새 버전, 저장소, 변경된 권한/게시자 표시. 확인과 설치를 별개 동작으로 구분한다.

소스는 ‘작품 제공자’, 패키지는 ‘설치 단위’, 저장소는 ‘패키지 목록 주소’라는 관계를 상세 설명에 짧게 넣는다.
만화/소설은 필터로 제공하고, 혼합 저장소를 억지로 둘로 등록시키지 않는다. Moya/Mangayomi/APK 구분은
호환성과 설치 대상을 설명하는 보조 정보로 둔다. 지원하지 않는 애니메이션 메뉴는 추가하지 않는다.

저장소 제거는 설치 패키지나 다운로드한 작품을 지우지 않는다. 패키지 제거도 책장 파일 삭제와 구분한다.
‘숨기기’는 이 기기의 표시 설정이며 ‘사용 중지’와 다르다. 기능을 분리해도 같은 설치 관리 API와 확인 절차를 사용한다.

업데이트 정책:

1. 1차: 지금 확인, 마지막 확인 시각, 업데이트 가능 개수, 선택한 항목 업데이트. 대량 작업은 제한된 순서로 진행하며
   성공/실패/검토 필요 항목을 따로 남긴다. 한 항목 실패가 나머지 결과를 지우지 않는다.
2. 2차: 앱 열 때 확인 또는 서버 주기 확인을 제공한다. 확인 주기를 줄여 서버·저장소에 반복 요청하지 않게 한다.
3. 자동 설치는 기본 꺼짐. 사용자가 켜더라도 새 권한·게시자 변경·다운그레이드는 기존 검토 절차를 거친다.
4. 웹 탭이 닫혀도 자동 확인/설치를 보장하려면 서버 스케줄러가 필요하다. UI 토글만 만들고 동작한다고 표시하지 않는다.

다운로드 공통 옵션은 ‘다운로드와 저장공간’에 한 번만 두고, 콘텐츠 소스에서 바로 이동하게 한다.
소스 상세에는 공통값을 보여 주며 해당 소스에 필요한 제한만 재정의한다.

## 8. 다운로드와 저장공간: self-host 의미에 맞추기

다운로드는 외부 사이트 → 서버 수집, 서버 → 현재 기기의 오프라인 저장, 파일 내보내기가 서로 다르다.
작업마다 `실행: 서버/이 기기`, `저장: 서버 책장/이 기기`를 알아볼 수 있게 표시한다.

| 항목                    | 1차 제안                                      | 추가 구현/제약                                                                             |
| ----------------------- | --------------------------------------------- | ------------------------------------------------------------------------------------------ |
| 다음 회차 미리 받기     | 끄기/1/2/3회, 현재 기능 이동                  | 기존 localStorage 값 이관. 받기가 끝나서 다음 작업이 무한 연결되지 않게 함                 |
| 동시 다운로드           | 현재 1~2개 제한 안에서 선택, 작업 범위를 표기 | 전체 제한은 큐별 제한과 다름. 서버 수집은 서버가 집행해야 여러 탭에서도 지켜짐             |
| 소스별 제한             | 소스가 허용한 한도를 초과하지 않음            | 실제 동시 수는 사용자 정책·소스 제한·호스트 상한 중 가장 작은 값                           |
| 작업 간 대기            | 필요 시 0/1/3/5초 등 작은 선택지              | 대기 중 취소 가능. 응답의 Retry-After 및 기존 재시도 정책과 중복시키지 않음                |
| 실패 처리               | 이유 표시·실패만 재시도·취소·완료 기록        | 재시도 횟수/대기는 기존 처리 확인 후 연결. 401/403/TLS 실패를 무한 재시도하지 않음         |
| 저장 사용량             | 서버/기기 별 사용량과 정리 가능한 캐시 구분   | 권한과 계측 API가 있는 대상만 표시. 추정치는 추정임을 명시                                 |
| 저장 형식               | 현재 만화 CBZ·텍스트 가져오기 형식을 설명     | 지원 없는 CBZ on/off 스위치를 만들지 않음. 원본 보존·내보내기와 별개                       |
| Wi-Fi에서만             | 기본 웹 화면에 엄격한 보장 옵션으로 넣지 않음 | self-host 서버는 휴대폰 회선을 사용하지 않으며 브라우저는 Wi-Fi 상태를 일관되게 식별 못 함 |
| 다운로드 위치/로컬 폴더 | 현재 대상 표시, 플랫폼이 지원하면 선택        | 브라우저에서 서버 임의 경로를 고르게 하지 않음. 서버 저장소는 운영 설정과 연결             |
| 읽은 후 삭제            | 이번 기본 범위 제외                           | 캐시 제거와 책장 원본 삭제를 먼저 분리해야 함. 이후 자동 캐시 정리만 별도 설계             |

다른 작품을 열거나 앱을 닫았을 때 작업이 계속되는지도 작업 유형별로 명확히 표시한다.
현재 서버 백그라운드 작업과 브라우저 생명주기에 묶인 작업을 먼저 구분하고, 설정 개편에 다운로드 엔진 전면 교체를 섞지 않는다.

## 9. 동기화와 설정의 적용 범위

기존 `SyncPanel`을 활용해 설정의 **동기화와 백업**에서 연결·마지막 성공·대기·실패·지금 동기화를 찾을 수 있게 한다.
소스에 로그인하는 것과 책장/진행률을 동기화하는 것을 다른 동작으로 설명한다.
동기화와 백업도 구분한다. 백업 파일 만들기/복원은 동기화 토글의 부수 효과가 아니다.

| 설정                       | 기본 저장 범위                  | 원칙                                                                                        |
| -------------------------- | ------------------------------- | ------------------------------------------------------------------------------------------- |
| 앱 테마·조작·리더 보기     | 현재 브라우저/기기              | 현재 정책 유지. 휴대폰 조판 변경이 데스크톱에 자동 적용되지 않음                            |
| 작품별 보기                | 현재 기기 + 작품                | 공통값 위에 명시한 필드만 덮어쓰기                                                          |
| 테마 프리셋                | 우선 현재 기기                  | 내보내기/가져오기는 가능하되 사용자 폰트·배경 파일 누락을 처리                              |
| 설치 패키지·서버 소스 연결 | 기존 호스트 계정/설치 대상 범위 | 계정별/호스트별 실제 API 범위를 먼저 확인. 다른 사용자까지 바뀌는 것처럼 잘못 표시하지 않음 |
| 서버 다운로드 정책         | 서버의 사용자 또는 관리자 범위  | 클라이언트 localStorage만으로 실행 제한을 강제하지 않음                                     |
| 표시 필터·즐겨찾기         | 우선 현재 기기                  | 나중에 동기화하려면 명시적 저장 계약 추가                                                   |

만화 프로필의 ‘기본값/이 작품만’은 별도 마이그레이션 단계로 처리한다. 기존 전역값이 있으면 기본값으로 유지하고,
기존 작품별 page crop을 보존한다. 과거에 복제 저장된 전체 프로필을 전부 ‘명시적 작품 override’로 해석하지 않는다.
새로 사용자가 바꾸는 필드부터 override 여부를 기록한다.

## 10. 구현 순서와 완료 조건

현재 체크 표시가 없는 항목은 모두 미구현이다. 각 단계는 문서 갱신과 별도 커밋으로 끝낸다.

| 단계  | 작업                                                  | 완료 조건                                                                          |
| ----- | ----------------------------------------------------- | ---------------------------------------------------------------------------------- |
| S0 ✅ | 공용 값 범위·설정 적용 범위 확정, 숫자 컨트롤 개선    | 트랙 터치/세로 스크롤로 값 불변. 손잡이·±·키보드 동작. 기존 유효 값 손실 없음      |
| S1    | 설정 메뉴 재편, 소스/기능 확장 분리, 동기화 진입 연결 | 이전 진입점 매핑. 모바일 상세/뒤로·포커스·저장 상태 정상. 기능 중복 설치 없음      |
| S2    | 텍스트/만화/PDF 빠른 보기와 프로필 적용 범위          | 읽던 위치 유지, 패널 조작으로 페이지 넘김 없음. 기본값·작품 override 의도대로 저장 |
| S3    | 텍스트 조판 옵션·사용자 테마                          | 측정/실제 렌더 동일, 재시작 후 값 유지. 오래된 설정 마이그레이션 확인              |
| S4    | 소스 목록·저장소·업데이트 작업 정리                   | 설치/업데이트 후 목록 일치, 혼합 저장소·부분 실패·검토 필요 상태 표현              |
| S5    | 다운로드 공통 정책과 사용량 화면                      | 지원하는 실행 경로에 정책이 실제 적용됨. 서버/기기 구분, 취소·재시도 동작          |
| 후속  | 자동 확인/자동 설치, 배경 이미지·그림자·세로 정렬 등  | 실제 수요와 각 호스트 기능 확인 후 개별 결정                                       |

S4는 S1 이후 S2/S3와 독립적인 작은 변경으로 진행할 수 있다. 서버 스케줄러나 다운로드 공통 제한이 큰 변경이면
S5 후속으로 분리한다. 그 기능이 완성되기 전에는 동작하지 않는 설정을 노출하지 않는다.
‘설정 분리’와 ‘렌더러/큐 변경’을 한 커밋으로 묶지 않는다.

## 11. 구현 시 최소 검증

새 옵션마다 전체 플랫폼 검사를 반복하지 않는다. 변경 경계의 집중 검사와 마지막 통합 브라우저 검사로 확인한다.

- 컨트롤: 트랙 탭/세로 pan, 손잡이 드래그·cancel, ±/숫자·키보드, 범위 끝/소수점.
- 설정 저장: 빠른 조절 후 즉시 닫기, 저장 실패 후 재시도, 작품 전환, 오래된 프로필 정규화.
- 리더: 긴 텍스트 중간 이어보기에서 글꼴/여백 변경, 한/두 쪽 전환, 만화 지연 로딩 중 패널 열기/닫기.
  값 변경 후 텍스트 anchor와 만화 페이지 위치가 유지되는지 검사한다. FPS만으로 통과 판정하지 않는다.
- 화면: 360/390px와 데스크톱, 큰 글자·키보드·reduced motion. 실기기 터치와 데스크톱 모바일 폭을 구분한다.
- 소스/다운로드: 혼합 저장소, 업데이트 중 일부 실패, 서버/기기 정책의 실제 적용, 기존 설치/복원 회귀 검사 재사용.
- 패키징: 새 공유 파일이 추가되면 `.dockerignore` 의존 파일 목록 확인. 웹 빌드 경로를 바꾼 단계에서는 Docker 빌드 1회.

합성 검사와 사용자 작품 검증을 구분해 기록한다. 실제 작품의 읽기 위치와 다운로드 상태를 검사용으로 덮어쓰지 않는다.

## 12. 추가 제안과 제외 범위

추천 추가 UX: 섹션별 되돌리기, 적용 범위 표시, 설정 검색, 변경된 항목 표시, 설치/다운로드 실패 원인에서 재시도로 바로 이동.
처음부터 일반 설정 엔진·동적 폼 생성기·새 전역 상태 프레임워크를 만들 필요는 없다.
원격 소스 사이트 변경, APK 호환 확대, 애니메이션 플레이어, Android WebView 재현은 이번 계획에 포함하지 않는다.

다음 구현은 S0부터 시작하는 것을 권한다. 제목과 세부 항목은 본 계획의 추천안을 기준으로 하되,
이 문서는 제품 코드 구현이나 배포 완료를 의미하지 않는다.

### 구현 기록

- `2026-09-20 · S0`: 트랙 탭으로는 값이 바뀌지 않고 44px 손잡이에서만 가로 드래그가 시작되는 숫자
  컨트롤을 적용했다. 세로 제스처는 페이지 스크롤에 남기고, 드래그 중에는 표시값만 바꾸며 놓을 때 저장한다.
  포인터 취소는 원래 값으로 돌아간다. ±, 직접 입력, 방향키·Page Up/Down·Home/End를 지원한다.
- 프로필 정규화와 설정 UI가 공유하는 범위 상수를 추가해 11~~40px 글자 크기와 420~~1280px 본문 폭 등
  이미 유효했던 저장값이 설정 화면에서 잘리지 않게 했다.
