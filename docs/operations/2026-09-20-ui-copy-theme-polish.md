# 설정·탐색 UI 마무리

## 범위

- 탐색 검색의 초기화 버튼에 테마 스타일과 44px 터치 영역 적용. 모바일에서는 별도 행 오른쪽에 배치해 세로 줄바꿈 방지.
- 설정 뒤로 버튼과 제목 사이 20px 간격을 화면 크기와 무관하게 공통 적용(PC 다운로드 하위 화면 포함). 중복된 페이지 설명과 저장 범위 문단을 제거하고 저장 상태는 짧게 표시.
- 설정·확장 관리·소스 연결·탐색·다운로드·동기화의 내부 구조 설명을 삭제하거나 축약. 삭제 시 보존 범위, 인증 정보 저장, 연결 제한, 실패 안내는 유지.
- 모양 → 앱 UI → 고급 옵션 → MOYA 로고 숨기기. 기기별 설정으로 저장하며 다른 기기에 동기화하지 않음. 로고를 숨겨도 홈 이동과 모바일 메뉴 접근 유지.
- 로고의 기존 실루엣을 테마 글자색으로 표시. 다크·미드나이트 강조색/버튼 글자색 조합, 경고·성공색의 고정 색상, 브라우저 상단 배경색 일치 수정.
- 사용자 테마 버튼 글자색은 상대 휘도로 대비가 높은 밝은색/어두운색 선택. 표지 원본·리더 본문 색상은 변경하지 않음.

## 색상 기준

[Material Web 색상 역할](https://github.com/material-components/material-web/blob/main/docs/theming/color.md)을 참고해 배경·강조색과 그 위의 글자색을 짝으로 사용했다. 기존 네 가지 기본 테마의 성격과 토큰 구조를 유지했으며 새 테마 시스템은 추가하지 않았다.

## 검증

- 관련 설정·확장·라이브러리 검사 및 기기별 저장 회귀 검사.
- 360/390/768/1366px 설정 브라우저 검사: 뒤로 버튼 간격, 가로 넘침, 저장 범위, 슬라이더 조작.
- 전체 앱 브라우저에서 모바일 탐색 검색 초기화, 테마별 화면, 로고 숨김 저장·새로고침·다시 표시 확인.
- 웹 타입 검사, 변경 파일 ESLint/포맷, CSS 검사.
- 기본 테마 네 종류의 본문·보조 글자·주요 버튼 대비: 모두 4.5:1 이상. 사용자 지정 본문/배경 조합까지 보장하는 것은 아님.

운영 서비스 배포는 별도다.

### 전체 앱 검사 범위

기존 전체 앱 시나리오의 첫 실행은 탐색·설치·업데이트·제거까지 통과한 뒤 숨겨진 리더 하단 버튼 선택에서 멈췄다. 재실행은 상세 화면의 브라우저 뒤로가기 후 탐색 대신 라이브러리로 이동해 멈췄다(page error는 두 실행 모두 0). 이를 전체 통합 검사 통과로 집계하지 않는다. 이번 변경의 탐색 모바일 배치는 첫 실행의 캡처로, 테마·로고 옵션은 별도 전체 App 세션에서 확인한다. 관련 없는 리더·탐색 이력 동작은 이 수정에서 변경하지 않았다.
