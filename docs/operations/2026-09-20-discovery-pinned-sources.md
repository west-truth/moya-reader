# 탐색 소스 고정과 상세 필터

## 합의한 범위

- 기존 사용자 탭과 여러 목록 구성 유지. 같은 소스의 인기·최신 두 목록도 합치지 않는다.
- 빠른 이동에서 열기와 고정을 분리. 카탈로그 소스는 탐색 안에서 열고 고정하면 상단 탭에 추가. 중복 고정 금지, 해제는 사용자 탭을 삭제하지 않는다. 파일 소스는 기존 폴더 탐색 유지.
- 고정 탭과 단일 카탈로그 목록 탭은 인기·최신·검색, 접을 수 있는 상세 필터, 작품 그리드, 더 불러오기 제공.
- 소스 제공 필터만 표시하며 필터 적용은 검색으로 실행. 편집 중 조건은 적용 전 요청하지 않는다.
- 여러 목록 탭의 전체 보기는 제자리 펼치기/접기로 변경. 실패해도 기존 결과 유지, 다음 페이지 재시도 가능.
- 세션 목록·표지 캐시 재사용. 탭별 검색·필터·추가 페이지·스크롤 복원. 연결 변경 시 이전 결과를 섞지 않는다.
- 기존 탐색 편집에서 고정 탭 이름·순서 변경. 고정 저장 실패는 화면에 알리고 기존 설정 보존.

PR #55의 UI 정리 위에서 구현한다. 초기 탐색 UI 구현은 서버/확장 런타임을 변경하지 않았다. 이후 표지·목록 속도 개선은 [별도 기록](2026-09-20-discovery-loading-performance.md)에 정리했으며, 운영 배포는 포함하지 않는다.

## 구현 기록

- 고정 표시는 기존 v1 설정에 선택 필드로 추가. 기존 사용자 탭·순서·목록 유지. 고정 탭을 여러 목록으로 편집하면 일반 탭으로 취급한다.
- 빠른 이동의 소스 이름은 탐색 안의 임시 소스를 열고, 핀은 고정 탭 추가/해제를 담당한다. 고정 후 메뉴의 핀 상태가 갱신되며 이름을 누르면 해당 탭으로 이동한다.
- 선택 필터는 16개 이하일 때 줄바꿈 가능한 버튼으로 표시. 긴 목록/텍스트/포함·제외/정렬은 기존 공통 컨트롤을 재사용한다.
- 페이지 결과는 기존 세션 캐시에만 보관하며 페이지 깊이·조건은 탐색 상태로 유지한다. 다음 페이지 중복 작품 제거, 반복 커서 종료, 실패 시 기존 결과 보존.
- 1개 소스의 인기·최신을 따로 구성한 탭은 계속 둘러보기로 표시한다. 단일 목록만 상세 탐색으로 전환한다.

## 검증 범위

- 관련 단위 검사 29개 통과: 고정/해제 시 기존 탭 보존, 페이지 중복 제거, 실패 후 재시도, 재진입 캐시, 기존 소스 화면.
- 브라우저 검사는 실제 DiscoveryScreen·필터·설정·세션 캐시에 제어 가능한 카탈로그 응답을 연결해 390/1366px에서 진행. 실제 외부 사이트 전체 호환성을 검증한 것은 아니다.
- 초기 브라우저 검사 후 모바일 검색/초기화 버튼 겹침을 발견해 수정. 수정 후 같은 시나리오가 두 해상도에서 통과했고, 버튼 겹침 검사와 캡처로 확인했다.
- 실행: `READER_UI_BROWSER_EXECUTABLE=<chromium> pnpm check:discovery-ux`.

웹 타입 검사·변경 파일 lint/포맷·CSS·의존성 순환 검사 통과. 테스트 데이터의 필수 importability 필드 누락을 보완하고 해당 테스트 3개와 웹 타입 검사를 다시 통과했다. 고정 탭 설정은 새로고침 후 유지되고, 검색 조건·페이지 깊이·위치는 같은 앱 세션에서 복원한다.
