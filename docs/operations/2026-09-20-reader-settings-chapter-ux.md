# 리더 설정·회차 작업 개선

## 범위

- **모양**은 앱 테마·로고 설정만 제공한다. 본문 테마, 글꼴, 밝기, 프리셋은 **리더 보기**에서 조절한다. 글꼴은 리더 전용이며 기존 책별 설정을 유지한다.
- 로컬 소설 회차의 `…`에서 읽음 표시, 이전 회차 모두 읽음, 제목 수정을 제공한다. 이전 회차는 화면의 정렬·검색 결과가 아니라 원래 회차 순서로 판단한다. 읽음 표시는 이어보기 위치를 변경하지 않는다.
- 제목 수정은 제목 메타데이터만 변경한다. 본문·회차 ID·주석·콘텐츠 리비전을 재생성하지 않으므로 TXT/EPUB 원본을 다시 해석할 필요가 없다. 원본 파일 자체를 수정하는 기능은 아니다.
- 탐색 미리보기의 좌우 화살표를 제거하고, 펼쳐 보기·접기·더 불러오기를 왼쪽 아래에 배치한다. 가로 스크롤은 유지한다.
- 다음 회차 미리 받기 여부/회차 수, 읽은 다운로드 자동 정리 여부/보관 회차 수를 기존 공통 설정의 `downloadPolicy`로 저장한다. self-host에서는 같은 계정의 기기에 공유하며 설정 진입·창 포커스 복귀 때 갱신한다. 기존 브라우저 정책은 공유 정책이 없을 때만 가져온다. 브라우저별 저장공간 사용량·권한은 공유하지 않는다.
- 페이지 모드에서 픽셀·줄 단위 블라인드를 사용할 수 있다. 현재 페이지를 모두 보여준 후 다음 페이지로 넘기며, 마지막 회차에서는 정지한다. 다음 회차 계속 읽기는 기존 선택 옵션을 따른다. 스크롤·RSVP 등 나머지 방식의 지원 범위는 유지한다.

## 저장 경로

- 회차 읽음·제목: IndexedDB와 hosted API 양쪽에서 구현한다. 현재 콘텐츠 리비전과 작품 소유권을 확인한다. hosted API는 `POST /api/books/:bookId/chapters/read`, `PATCH /api/books/:bookId/chapters/:chapterId`를 사용한다.
- 다운로드 정책: 기존 `/api/settings`와 공통 설정 저장 경로를 사용한다. 이전 클라이언트가 이 필드 없이 설정을 저장해도 서버 정책을 지우지 않는다. 별도 테이블·스케줄러는 추가하지 않는다.
- 자동 정리의 실행 시점과 보호 조건은 기존과 같다. 공유된 정책이 서버 상주 정리 작업을 새로 만드는 것은 아니다.

## 검증

- IndexedDB: 이전/현재 회차 읽음 표시, 제목 수정, 이어보기 및 본문 보존, 오래된 리비전 거부.
- 격리 PostgreSQL: 회차 작업의 소유권·리비전 확인, 제목/읽음 저장, 이어보기 보존. 다운로드 정책 저장·계정 분리·잘못된 값 거부·구형 클라이언트 저장 후 보존.
- 설정 저장/리더 자동 스크롤 관련 단위 검사와 웹·서버 타입 검사.
- Chromium: 설정 360/390/768/1366px, 회차 작업 390/768/1366px, 탐색 펼치기/더 불러오기 390/1366px, 페이지 블라인드 320/834px.
- 페이지 블라인드 재현 명령: `node scripts/performance/auto-scroll-smoke.mjs --paginated` (`READER_UI_BROWSER_EXECUTABLE` 또는 `READER_UI_BROWSER_CHANNEL` 지원).

운영 데이터나 실행 중인 Docker 서비스는 변경하지 않았다.

## CI 후속 정리

기존 페이지 뷰어 테스트의 가짜 DOM에 `replaceChildren()`이 빠진 것을 수정했다. 해당 회귀 검사는 계속 실행한다. 중복 테스트와 무조건 실행하던 무거운 검사 정리는 [CI 실행 범위 기록](2026-09-20-ci-scope.md)을 따른다.
