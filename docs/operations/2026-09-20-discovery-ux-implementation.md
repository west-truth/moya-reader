# 탐색 홈 구현 기록

기준 계획: [탐색 UX 계획](2026-09-20-discovery-ux-plan.md).
브랜치: `feat/discovery-home`. 설정 PR #52 코드 위에서 작업. 운영 배포 없음.
사용자 확정: 주 진입점은 좌측 사이드 메뉴, 모바일은 동일 메뉴 안에 제공.

## 작업 기록

### 세션 표지 캐시

- remote/local 설치 소스의 개별 64개 URL 캐시를 공통 `SessionCoverCache` 정책으로 교체.
- 200개/Blob 32MiB 기준 LRU, DOM에서 사용 중인 URL은 퇴출에서 제외.
- 동일 키 요청 공유, 한 소비자가 취소돼도 공유 요청 유지, 세대 변경/정리 시 늦은 응답 폐기.
- 30초 요청 기한과 실패 재시도 유예. 표지가 없는 소스의 기존 optional 반환 유지.
- 표지는 세션 메모리에만 저장. 기존 라이브러리 영속 표지와 서버 정책은 변경하지 않음.
- 캐시·조회·기존 메뉴/내비게이션/원격 클라이언트 테스트 묶음 51개 통과(첫 검사). 제품 브라우저 검증은 아래에 최종 결과 기록.

### 탐색 화면·메뉴

- 접기 가능한 라이브러리/책장/소스 메뉴와 탐색 진입점.
- 탭·목록 편집, 추천 구성, 인기/최신·분류 프리셋, 소스별 검색.
- 기존 상세/회차 화면 연결 및 기존 브라우저 히스토리 통합.
- 탐색 세션 조회 캐시, 두 소스 병렬·동일 소스 직렬 조회, 화면 근처 표지 요청.
- 구현 중 실제 App 검사에서 발견한 상세 진입 인수 오류 수정. 환경 의존성 경로도 임시 작업 폴더 내에서 교정.

## 완료 범위와 경계

- D1 핵심 완료: 세 메뉴 독립 접기·기기 저장, 사이드 탐색 진입, 모바일 동일 메뉴, 탭/소스 구성과 기존 상세 연결.
- D2 핵심 완료: 소스별 목록/실패 격리, 목록 요청 공유·동일 소스 직렬/전체 2개 병렬, 표지 4개 조회 대기열, 캐시·위치 복원.
- D3 핵심 완료: 탭/목록 편집(드래그와 이동 버튼), 표시 밀도, 숨김/삭제/되돌리기, 분류 프리셋 저장, 단일/탭 전체 소스 검색.
- 홈은 목록당 최대 12개 미리보기. 검색 결과의 다음 페이지와 상세는 `전체 보기`에서 기존 소스 화면으로 연결한다.
- 복원은 **세로 섹션 ID+상대 위치, 가로 목록의 픽셀 위치**를 저장한다. 작품 단위의 가로 앵커 재탐색까지 일반화하지 않았다. 기존 목록을 유지하고 갱신은 명시적으로 적용한다.
- 표지 32MiB/200개는 설치 소스 어댑터 캐시 기준이며 화면에서 참조하는 이미지는 일시 초과할 수 있다. 홈의 먼 카드 이미지 요소는 비워 메모리 회수가 가능하게 한다. 외부 직접 HTTPS URL 경로는 기존 브라우저 캐시를 따른다.
- 진행 중인 공유 목록/표지 조회는 세션 캐시를 위해 완료할 수 있다. 세션 종료 때 취소하며 요청 기한을 둔다. 화면 이동만으로 공유 요청을 반복 취소하지 않는다.
- Suwayomi/텍스트 서버처럼 여러 하위 소스를 폴더로 반환하는 연결은 기존 폴더 진입을 활용한다. 실제 하위 소스에서 분류를 고른 뒤 `탐색에 목록 추가`로 바로가기를 저장할 수 있다.
- 실제 외부 사이트의 콘텐츠 제공 여부를 이번 검사로 보증하지 않는다. 이번 브라우저 검증은 실제 제품 App과 실행기를 사용하되 합성 확장·격리 DB/API로 수행했다. 운영 소스 설치·다운로드·설정은 변경하지 않았다.
- D4(구성 내보내기/자동 동기화/기본 시작 화면 등)는 계획대로 선택적 후속 작업. 소스 즐겨찾기 기준 사이드 목록 축약도 기존 바로가기 보존을 우선하여 별도 후속으로 둔다.

## PR #53 CI 수정 및 편집 UX 보완

- `hosted-source` 실패: 서버 타입 검사에는 `DOM.Iterable`이 없어 `document.images`의 전개 연산이 TS2488 발생. 공유 캐시에서 `Array.from`으로 읽어 서버 설정 변경 없이 해결.
- 편집은 한 번에 한 탭만 펼치는 구조. 접힌 탭에는 이름·목록 수·표시 여부 표시. 탭 내부 목록도 개별 요약 행으로 접고 펼침.
- 상단 탭 추가/모두 접기, 추가한 탭 이름 선택 및 목록 소스 입력에 포커스. 기존 순서 이동·숨김·삭제·되돌리기·저장/취소 유지.
- 추천 구성 교체는 별도 접힌 항목에 설명과 함께 배치. 모바일에서도 저장/취소 하단 고정 유지.
- 서버/웹/스크립트 타입 검사, 관련 캐시·조회 테스트 6개, 실제 App 격리 브라우저 검사 수행. 접기 후 초안 보존·추가·저장·재접속 및 360/390px 편집 화면 확인.
- #52 병합에 따라 #53 기준 브랜치를 `main`으로 변경. 운영 배포 없음. GitHub 새 CI 결과는 PR에서 확인.

### 후속 CI 실패: 브라우저 없는 소스 화면 테스트

- 타입 검사 수정 후 `hosted-source`가 `SourceHubScreen`의 기존 동작 테스트에서 `window is not defined`로 중단됨. 로컬에서도 동일 실패 재현.
- `CollapsibleNavigation`의 이벤트 등록 효과에 브라우저 존재 확인 추가. 테스트를 우회하거나 DOM 목업을 주입하지 않고 브라우저 외 렌더링에서도 기존 메뉴 동작을 유지.
- 기존 소스 화면·라이브러리 검사 2파일 51개 통과, 해당 파일 lint 및 diff 검사 통과. CI와 동일한 `check:web-server`와 원격 CI 후속 결과를 확인한다.
