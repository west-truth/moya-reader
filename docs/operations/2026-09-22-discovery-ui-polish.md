# 탐색 고정 표시와 목록 갱신 UI 정리

- 고정 탭을 inline-flex로 배치해 핀과 글자를 세로 가운데에 맞췄다. 탭 스크롤바를 얇게 하고 간격을 정리했다.
- 빠른 이동의 고정 버튼에 잘못 적용되던 space-between 정렬을 해제했다. 긴 소스 이름은 줄바꿈하고 화살표·핀은 줄어들지 않게 했다.
- 둘러보기 목록, 펼친 목록, 고정 소스 화면의 제목 오른쪽에 44px 터치 영역의 새로고침 아이콘을 배치했다. 로딩 중에는 중복 요청을 막고 회전 표시를 제공하며 reduced-motion에서는 회전하지 않는다.
- 이미 목록이 있으면 갱신 실패 배너/큰 재시도 버튼을 표시하지 않는다. 목록을 유지하고 아이콘의 테마 강조색, 툴팁과 접근성 이름으로 재시도를 안내한다. 대기 중인 새 목록도 같은 아이콘으로 반영한다.
- 최초 목록 로딩에 실패한 경우는 짧은 본문 안내를 유지한다. 소스 연결/목록 지원 안내와 캐시·네트워크 정책은 변경하지 않는다.

## 확인

기존 탐색 브라우저 검사에 핀 정렬, 제목 오른쪽 새로고침, 기존 목록을 유지한 갱신 실패·재시도 검증을 추가했다. 격리 Chromium에서 390px/1366px의 고정·필터·펼침·더 불러오기·실패 복구·재접속·상세 왕복이 통과했다. 브라우저 오류가 없으며 관련 7개 단위 테스트와 타입/lint/CSS 검사도 통과했다. 운영 서비스는 변경하지 않았다.
