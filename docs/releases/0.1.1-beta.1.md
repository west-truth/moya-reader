# Moya for Windows 0.1.1-beta.1

Windows x64 베타 후보입니다. 공개 배포 전 검증 중이며 아직 정식 릴리즈가 아닙니다.

## 주요 기능

- Docker 설치 없이 사용하는 PC 서재와 기존 self-host 직접 접속
- TXT·EPUB·PDF·만화 읽기, 확장 소스 다운로드, 백업·복원
- 설정의 서재 선택·원격 접속, 처리량에 따른 다운로드·가져오기 진행률

## 이번 수정

- Windows에서 사용자 글꼴과 다운로드한 표지를 저장하지 못하던 문제 수정
- 중앙 탭으로 연 리더 도구 유지, 자동 스크롤 진입 버튼 추가
- 선택 없는 하이라이트 생성 차단, 여러 문단의 선택 저장·삭제 개선
- 회차 목록의 좌우 방향키 이동, 픽셀 스크롤 속도 범위 확대
- 기존 서버 연결 실패의 단계·원인 표시
- AI 작업이 동시에 들어오면 사용자별 실행 제한을 넘을 수 있던 오류 수정

## 설치 및 호환성

- 기존 테스트 앱과 같은 식별자를 사용합니다. 업데이트 전 앱을 종료하고 서재를 백업하세요.
- 별도 서버끼리 자동 복제하거나 병합하지 않습니다. 같은 서버로 접속하거나 백업으로 이전합니다.
- 앱 안에서 기존 self-host를 열려면 데스크톱 WebView 접속을 지원하는 서버 버전이 필요합니다.
- 설치본은 서명되지 않았습니다. Windows나 브라우저에서 경고가 표시될 수 있습니다.
- 인용문만 저장한 기존 하이라이트는 같은 문장이 반복되는 문단에서 위치 구분에 제약이 있습니다.

## 검증과 배포 상태

- [Windows 앱·설치·이전 테스트 버전 업데이트 실행](https://github.com/west-truth/moya-reader/actions/runs/36224339712): 후보 코드 `77d3fa1`. 결과 JSON과 실행의 성공 여부를 함께 확인합니다.
- [PR #62](https://github.com/west-truth/moya-reader/pull/62): 최신 공통 CI와 검토 결과, 테스트 설치본 위치.
- 공개 GitHub Release는 아직 게시하지 않았습니다. 최종 바이너리 고지·대응 소스 검토가 남아 있습니다.
- Windows Cargo 고지 324개와 외부 소스 아카이브 56개를 확보했습니다. 재생성 방법과 미확인 범위는 [소스 자료 안내](../../third_party/windows-sources.md)에 있습니다.

테스트 설치본과 대응 소스의 SHA-256을 함께 제공합니다. CI 러너에서 개발 도구를 PATH에서 제외한 설치 검사는 깨끗한 Windows VM 검증과 구별합니다.
