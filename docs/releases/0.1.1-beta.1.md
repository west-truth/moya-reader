# Moya for Windows 0.1.1-beta.1

Windows x64 공개 베타입니다. [설치본 다운로드](https://github.com/west-truth/moya-reader/releases/tag/desktop-v0.1.1-beta.1).

## 2026-09-27 설치본 갱신

공개 EXE를 `98f6492` 빌드로 교체했습니다. Quick Tunnel의 HTTP 415 오류와 스크롤 몰입형 진입, 자동 읽기 재생·일시정지 및 항상 오버레이 표시 옵션을 포함합니다. 기존 앱을 트레이에서 완전히 종료한 뒤 새 설치본으로 업데이트하세요. **수동 파일 교체는 필요 없습니다.** 표시 버전은 기존과 같은 `0.1.1-beta.1`입니다.

## 주요 기능

- Docker 설치 없이 사용하는 PC 서재와 기존 self-host 직접 접속
- TXT·EPUB·PDF·만화 읽기, 확장 소스 다운로드, 백업·복원
- 설정의 서재 선택·원격 접속, 처리량에 따른 다운로드·가져오기 진행률

## 이번 수정

- Windows에서 사용자 글꼴과 다운로드한 표지를 저장하지 못하던 문제 수정
- 중앙 탭으로 연 리더 도구 유지, 자동 스크롤 진입 버튼 추가
- 선택 없는 하이라이트 생성 차단, 여러 문단의 선택 저장·삭제 개선
- 회차 목록의 좌우 방향키 이동, 픽셀 스크롤 속도 범위 확대
- 기존 서버 연결 실패의 단계·원인 표시
- AI 작업이 동시에 들어오면 사용자별 실행 제한을 넘을 수 있던 오류 수정

## 설치 및 호환성

- 기존 테스트 앱과 같은 식별자를 사용합니다. 업데이트 전 앱을 종료하고 서재를 백업하세요.
- 별도 서버끼리 자동 복제하거나 병합하지 않습니다. 같은 서버로 접속하거나 백업으로 이전합니다.
- 앱 안에서 기존 self-host를 열려면 데스크톱 WebView 접속을 지원하는 서버 버전이 필요합니다.
- 설치본은 서명되지 않았습니다. Windows나 브라우저에서 경고가 표시될 수 있습니다.
- 인용문만 저장한 기존 하이라이트는 같은 문장이 반복되는 문단에서 위치 구분에 제약이 있습니다.

## 검증과 배포 상태

- [수정본 Windows 빌드 성공](https://github.com/west-truth/moya-reader/actions/runs/36228370821): `98f64921911e2d1f13b78c6ff52d46845a8b954b`, [PR #63](https://github.com/west-truth/moya-reader/pull/63).
- 관련 로컬 검사·모바일 크기 Chromium 검사 및 실제 Quick Tunnel의 수정 전후 비교를 통과했습니다. 이번 수정본의 전체 CI와 Windows 장시간 앱·설치 검증은 재실행하지 않았습니다.
- [최초 설치본의 Windows 앱·업데이트 검사](https://github.com/west-truth/moya-reader/actions/runs/36224788487)는 이전 빌드 `550893b`의 증거입니다. 깨끗한 Windows VM·실제 다른 기기 검증은 포함하지 않습니다.
- 현재 EXE에 대응하는 소스는 릴리즈의 `moya-windows-sources-98f6492.tar.gz`입니다. 태그 및 GitHub 자동 생성 Source code는 최초 공개 커밋을 유지합니다.
- 설치본·소스 자료의 SHA-256은 함께 제공하는 `SHA256SUMS.txt`에 있습니다. 외부 소스 자료 범위와 재빌드 조건은 [소스 자료 안내](../../third_party/windows-sources.md)를 참고하세요.
