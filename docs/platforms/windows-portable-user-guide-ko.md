# Windows 포터블 Moya 사용 안내 (시험용 후보)

현재 `Moya.exe`는 Windows x64 시험용 후보입니다. 정식 릴리즈 전까지 대용량 파일·백업과 실제 소스 사이트의 전체 동작은 보장하지 않습니다. [진행 상태와 남은 검증](2026-09-23-desktop-release-plan.md)을 확인하세요.

## 시작과 데이터 이동

1. 쓰기 가능한 폴더에 `Moya.exe`를 놓고 실행합니다. Moya 설치 프로그램은 없습니다. PC에 Microsoft Edge WebView2 Runtime이 없으면 안내에 따라 공식 Evergreen Runtime을 먼저 설치합니다. 모든 PC의 최초 오프라인 실행은 보장하지 않습니다.
2. 첫 실행 시 같은 폴더에 `MoyaData/`가 생깁니다. 실행기와 WebView 데이터가 준비되는 동안 잠시 기다립니다.
3. PC나 폴더를 옮길 때는 Moya를 종료하고 **`Moya.exe`와 `MoyaData/`를 함께** 복사합니다. EXE만 복사하면 빈 서재로 시작합니다.
4. 새 후보로 교체할 때도 먼저 Moya를 종료하고 EXE만 교체합니다. `MoyaData/`는 지우지 않습니다. 이전 EXE와 폴더의 별도 복사본을 보관한 뒤 첫 실행을 확인하세요.

현재 서재와 설정은 `MoyaData/webview/`의 WebView 저장소에 있습니다. 파일을 개별적으로 골라 복사하면 일관된 백업이 되지 않습니다. 앱 내 백업은 현재 로컬 저장소의 **압축 전 256MiB·500개 항목** 제한이 남아 있습니다. 큰 서재의 복구 수단으로 이 버튼만 믿지 마세요.

## 소스와 로그인

소스 설정에서 실행 위치를 `이 PC`로 선택하면 로컬 확장 실행기를 사용합니다. 기본 프록시와 소스별 프록시를 설정할 수 있습니다. 서버에 연결하더라도 이 선택을 바꾸기 전까지 로컬 확장 설치본은 유지됩니다.

소스 설정과 로그인 정보를 포터블 폴더에 저장하려면 **소스 보관소**에서 암호를 만드세요. 만들기 전에 입력한 이번 실행의 설정도 함께 저장됩니다. 보관소를 만든 뒤에는 앱을 다시 켤 때 잠금을 풀어야 저장한 연결 설정을 사용할 수 있습니다. 잠긴 설정을 무시하고 직접 연결하지 않습니다. 소스 작업이 진행 중이면 잠금 전환은 완료 후 다시 시도하세요. 다른 PC로 옮긴 뒤 같은 암호로 잠금을 풀 수 있습니다. 암호를 잃으면 저장한 로그인 정보를 복구할 수 없습니다. 사이트 브라우저 쿠키와 AI/API 키는 이 보관소의 이동 보장에 포함되지 않아 다시 로그인하거나 설정해야 할 수 있습니다.

기본 JS 소스와 Mangayomi JS 확장용 Node 실행기는 EXE에 포함됩니다. 브라우저 조작이 필요한 일부 소스는 시스템 Microsoft Edge가 필요할 수 있습니다. APK 확장의 Java 실행기는 기본 후보에 포함되지 않으며 별도 실험 대상으로 취급합니다.

## 현재 제한

- Windows 11 x64 우선 후보이며 Windows 10·ARM64·다른 OS는 아직 검증하지 않았습니다.
- EPUB 파싱은 파일 전체를 한 번에 버퍼링하지 않도록 개선했지만, 원본·이미지와 백업은 아직 브라우저 저장소 경로를 사용합니다. 수 GiB 가져오기·백업을 지원한다고 표시하지 않습니다.
- 앱을 종료하면 진행 중이던 다운로드는 멈춥니다. 저장된 대기열은 다음 실행에서 수동으로 이어받을 수 있습니다.
- 앱 자체를 자동 교체하지 않습니다. 새 버전 확인·EXE 교체는 정식 릴리즈 검증이 끝나기 전까지 수동으로 수행하세요.
